React workspace

The frontend now exposes streamed research, pipeline metrics, live web sources, and tag facets instead of hiding those capabilities behind backend-only routes.

What changed in search

Graphite now stores tags persistently, exposes semantic note search, and reranks the top window with a cross-rerank stage instead of stopping at lexical or embedding-only ranking.

  • New `note_tags` and `tags` tables in local SQLite.
  • `/api/notes/search` exposes ranked matches with score breakdowns.
  • ReAct note search now uses the same retrieval path as the product.

What changed in research

The research page is no longer a single blocking POST. It now consumes an SSE stream with progress, plan blocks, report chunks, and pipeline metrics.

  • Brave is the primary web provider, with DuckDuckGo fallback.
  • Chunked report updates reduce perceived latency.
  • Altimate metrics attach cost, lineage, and latency to each run.

Why Altimate matters

Altimate’s value here is not cosmetic. It gives the team control over the pipeline’s reliability, explainability, and cost at the exact places where RAG systems usually become opaque.

  • Coverage gaps become measurable before they degrade answers.
  • Lineage makes every report traceable to ranked evidence.
  • FinOps keeps token usage small enough to scale safely.
Shipped feature Technical effect User-facing impact
pgvector HNSW path Approximate nearest-neighbor search over `note_embeddings` and `memory_vectors`. Lower retrieval latency and a realistic path to larger note corpora.
Brave-first live search Primary structured web search with DuckDuckGo fallback and provider reporting. Research can cite fresh external context instead of relying only on saved notes.
SSE research streaming Progress, plan, chunk, metrics, sources, and result events over one request. Users see work happen before the whole report is finished.
Persistent auto-tagging Stored tags with backend filters and visible note facets. Stocks, ML, career, and related clusters are browsable instead of hidden inside note text.
Hybrid reranking Lexical + semantic + cross-rerank scoring on the top candidate window. Better top-of-list source quality, especially for ambiguous queries.
