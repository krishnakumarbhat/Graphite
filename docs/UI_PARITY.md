# UI Parity Rules (Web + Mobile)

## Goal
Keep web and mobile visually consistent while respecting platform patterns.

## Must match
- Content hierarchy (notes, workflow, settings)
- Labels and terminology
- Empty states and primary actions
- Theme behavior (light/dark)

## Can differ
- Navigation container patterns (tabs, top bars)
- Spacing optimized for form factor
- Input ergonomics and gesture affordances

## Contribution checklist
For UI PRs affecting either app:
- Verify web responsive behavior.
- Verify mobile native behavior.
- Update screenshots for both where relevant.
