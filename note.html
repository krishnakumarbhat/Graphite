🏗️ Pipeline Architecture

📝 User Note (title + content)
↓
✂️ Chunker — 1400 chars, 180 overlap
↓
🔢 Gemini text-embedding-004 → 768-dim vector
↓
🗄️ SQLite (local) / pgvector (prod) — cosine similarity
↓
🤖 ReAct Agent (Gemini 2.0 Flash) — Reason → Act → Observe
↓
💬 Synthesized Answer with Citations [S1] [S2]...

🗃️ Vector Storage: SQLite → pgvector

Local Dev (SQLite)

-- note_embeddings table
CREATE TABLE note_embeddings (
  note_id TEXT PRIMARY KEY,
  embedding_json TEXT NOT NULL,  -- JSON array of 768 floats
  updated_at TEXT NOT NULL
);

Production (pgvector)

CREATE EXTENSION IF NOT EXISTS vector;
ALTER TABLE notes ADD COLUMN embedding vector(768);
CREATE INDEX ON notes USING hnsw (embedding vector_cosine_ops)
  WITH (m = 16, ef_construction = 64);

-- Query
SELECT id, title, 1 - (embedding <=> $1) AS score
FROM notes ORDER BY embedding <=> $1 LIMIT 5;
